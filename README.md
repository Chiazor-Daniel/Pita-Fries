# Pita Fries — React Native Commerce App

A **React Native** food-service app for **Pita Fries** built with `@react-navigation/native` and shared-element transitions.

- **Auth** — register / login / go-to-login
- **Home** — three home layouts (`home1`, `home2`, `home3`) plus a logging screen
- **Products** — product listing with detail/product-view screens and previews
- **Loyalty & Receipts** — loyalty screen, receipt screens, receipt progress UI

## Run

```bash
npm install
# Android: npm run android   ·   iOS: npx pod-install && npm run ios
```
